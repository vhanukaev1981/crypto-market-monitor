# $100 Live Canary Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a fail-closed, Spot-only live canary with an aggregate USD 100 capital ceiling and a separate human-controlled activation gate.

**Architecture:** Preserve the existing signal/risk/readiness pipeline and Paper default. Add a pure live-canary policy boundary first, then a dry-run-capable exchange adapter and reconciliation lock, then wire exact-head CI and autonomous development qualification. Credentials and actual live enablement remain a separate security-sensitive activation step after code readiness.

**Tech Stack:** Node.js 22.13.0, ES modules, node:test, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-03-live-canary-100-design.md`

## Global Constraints
- Spot only; aggregate live-canary capital <= USD 100.
- No leverage, margin, futures, derivatives, withdrawals or transfers.
- Paper remains default; Live Canary defaults disabled.
- Existing risk/exposure/5% drawdown/OOS protections remain mandatory.
- Missing/stale/ambiguous evidence fails closed.
- No secrets in repository.
- PR #8 remains Draft; no merge to main.
